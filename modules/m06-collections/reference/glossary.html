Глосарій: Kotlin Collections

Канонічні означення термінів курсу. У всіх уроках вживаються саме ці слова — якщо десь трапляється синонім, вважайте його неточністю.

Типи колекцій

Колекція (Collection)
Структура даних, що зберігає групу елементів одного типу і дозволяє працювати з ними як з єдиним цілим.

List
Впорядкована колекція, що дозволяє дублікати елементів і доступ за індексом. Read-only інтерфейс — без методів зміни.
Уточнення: read-only не означає, що обʼєкт у пам'яті незмінний — див. Аліасинг.

MutableList
List плюс методи зміни: add(), remove(), removeAt(), clear().

Set
Колекція, де кожен елемент унікальний (дублікати автоматично відкидаються). У Kotlin за замовчуванням зберігає порядок додавання.

MutableSet
Set плюс методи зміни: add(), remove(), clear().

Map
Колекція пар "ключ → значення", де кожен ключ унікальний. Не плутати з функцією map() (див. нижче) — назва одна, суть різна.

MutableMap
Map плюс методи зміни: put(), оператор [key] = value, remove().

Функції над колекціями

map() (функція)
Застосовує лямбду до кожного елемента колекції й повертає нову колекцію того самого розміру з результатами.
Avoid: "перетворення" без уточнення, коли поруч є тип Map — плутає новачків.

filter() / filterNot()
Повертає підмножину елементів, для яких лямбда-умова істинна (filter) або хибна (filterNot). Результат може бути меншим за оригінал.

forEach()
Виконує дію для кожного елемента, не повертаючи нової колекції. Заміна циклу for, коли результат не потрібен.

find() / firstOrNull()
Повертають перший елемент, що підходить під умову, або null, якщо такого немає. first() (без Null) натомість кидає виняток.

sortedBy() / sortedByDescending()
Повертають новий список, впорядкований за значенням, яке обчислює лямбда — за зростанням або спаданням відповідно.

Агрегація (aggregate)
Загальна назва операцій, що "стискають" колекцію в одне значення: count(), sum(), average(), maxOrNull(), minOrNull().

groupBy()
Розкладає колекцію на Map<K, List<V>>: ключ — результат лямбди, значення — список усіх елементів з цим результатом.

fold()
Загальний спосіб звести колекцію до одного значення за явно вказаним стартовим значенням і функцією "накопичувач + елемент → новий накопичувач". Безпечний для порожньої колекції.

reduce()
Те саме, що fold(), але без явного стартового значення — бере перший елемент колекції як старт. Кидає виняток на порожній колекції.

flatMap()
Комбінація map() і "розплощення": застосовує лямбду, що повертає колекцію для кожного елемента, і склеює всі результати в один плаский список.

zip()
З'єднує дві колекції в список пар Pair, по позиції.

associate() / associateWith() / associateBy()
Перетворюють колекцію на Map: associateWith — елемент стає ключем, лямбда дає значення; associateBy — навпаки.

Практика та типові пастки

Аліасинг (aliasing)
Ситуація, коли дві змінні вказують на один і той самий обʼєкт колекції в пам'яті. Зміна через одну змінну видима через іншу.
Avoid: "копіювання посилання" як синонім справжньої копії — це протилежні речі.

Копія (copy)
Новий, незалежний обʼєкт колекції з тим самим вмістом. Отримується через toList(), toMutableList(), toSet(), toMap().

Builder-функція
Функція виду buildList { }, buildSet { }, buildMap { }: усередині лямбди колекція мутабельна, назовні повертається готовий read-only результат.

Sequences

Sequence
Тип колекції з лінивою (по одному елементу через увесь ланцюжок) обробкою, без створення проміжних колекцій на кожному кроці.

Intermediate операція
Операція на Sequence (наприклад map, filter), яка лише описує крок обробки й сама по собі нічого не обчислює.

Terminal операція
Операція на Sequence (наприклад toList(), first(), sum()), яка запускає фактичне обчислення всього ланцюжка.
