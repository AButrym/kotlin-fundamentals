Підсумкова практика: колекції разом

Що ви вже знаєте

Ви пройшли весь курс: List/Set/Map, map/filter/forEach, сортування й агрегацію, fold/reduce/flatMap/zip, mutable-пастки та Sequences. Цей урок нічого нового не пояснює — він перемішує все, щоб перевірити, чи тримається матеріал разом, а не тільки "по одному уроку за раз".

Один наскрізний приклад: чек із покупками.

data class Purchase(val item: String, val price: Int, val category: String)

val receipt = listOf(
    Purchase("хліб", 35, "їжа"),
    Purchase("молоко", 42, "їжа"),
    Purchase("зошит", 28, "канцелярія"),
    Purchase("ручка", 15, "канцелярія"),
    Purchase("молоко", 42, "їжа")
)

Спробуйте самостійно

Перш ніж дивитись підказки нижче — спробуйте написати код для кожної задачі у Kotlin Playground (офіційний онлайн-редактор Kotlin, не потребує встановлення).

  1. Загальна сума чека (підказка: агрегація з уроку 5, або fold з уроку 6).
  2. Список унікальних категорій товарів у чеку (підказка: урок 3 + урок 4 — трансформація в Set).
  3. Товари, згруповані по категорії (підказка: урок 5).
  4. Мапа "назва товару → ціна", без дублікатів назв (підказка: урок 6, associateWith чи associate).
  5. Найдорожчий товар у чеку (підказка: урок 5, maxByOrNull).
  6. Якщо цей список товарів прийшов з бази даних на мільйон рядків і потрібно лише перший товар дорожчий за 1000 — чи використали б ви List чи Sequence? Чому? (підказка: урок 8).
Самоперевірка

Один із варіантів рішення (спробуйте спочатку самі, потім порівняйте):

val total = receipt.sumOf { it.price }                       // 1.
val categories = receipt.map { it.category }.toSet()          // 2.
val byCategory = receipt.groupBy { it.category }               // 3.
val priceByItem = receipt.associate { it.item to it.price }    // 4.
val mostExpensive = receipt.maxByOrNull { it.price }            // 5.
// 6. Sequence — через розмір даних (мільйон) і зупинку на першому знайденому

Змішана перевірка (усі теми разом)

У receipt вище скільки унікальних назв товарів (не категорій)?

Який тип матиме receipt.groupBy { it.category }?

Якщо val copy = receipt.toMutableList(), а потім copy.add(...) — чи зміниться оригінальний receipt?

Куди далі

Цей курс дав робочу основу: створення й вибір правильної колекції, основні та просунуті функціональні операції, типові пастки з mutable-колекціями, і коли варто сягнути по Sequences. Природні наступні кроки — власні generic-класи, робота з null у колекціях (filterNotNull, mapNotNull) та корутини для асинхронної обробки даних.

Питання після курсу?

Якщо якась із задач вище не піддається — це нормальний сигнал, який саме урок варто переглянути ще раз. Розкажіть викладачу/агенту, на якому кроці застрягли, і разом розберете конкретний приклад.
