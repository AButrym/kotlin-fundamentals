5. Типові помилки

  • забули open на класі чи методі — «This type is final» / «is final and cannot be overridden»;
  • забули override — компілятор не дозволить мовчки перекрити метод;
  • очікують, що pet.fetch() працює для змінної типу Animal;
  • кладуть у тіло data class властивості, що мають входити в == і copy.
