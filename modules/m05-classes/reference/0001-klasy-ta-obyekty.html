Класи та об’єкти — шпаргалка

Для уроків 1–4: клас, конструктор, методи, видимість і властивості.

1. Клас і об’єкт

ЗаписЗначення
class Point { var x = 0 }клас із властивістю; об’єкт: val p = Point()
p.x, p.x = 3читання / запис властивості
val / var у класінезмінна / змінна властивість
Point()виклик конструктора (без new)

2. Конструктори

ЗаписЗначення
class P(val x: Int, y: Int)первинний конструктор: x — властивість, y — лише параметр
class P(val x: Int = 0)значення за замовчуванням; P(x = 5) — іменований аргумент
init { require(x > 0) { "…" } }блок init: виконується при створенні; require перевіряє дані
constructor() : this(0, 0)додатковий конструктор (мусить викликати this(…))

3. Методи, this, toString

ЗаписЗначення

this.x = xthis: властивість поточного об’єкта, коли ім’я «затінене» параметром
override fun toString(): String = "($x, $y)"текстове подання для println і шаблонів "$p"

4. Видимість та властивості з логікою

ЗаписЗначення
private val dataprivate: доступно лише всередині класу (за замовчуванням — public)
var b: Int = 0
  private set		читати можна всім, змінювати — лише клас
val area: Int
  get() = w * h		обчислювана властивість (немає власного поля)
var t: Int = 20
  set(v) { if (v in 10..30) field = v }		власний setter; field — приховане поле

5. Типові помилки

  • забули val/var у конструкторі й дивуються, що p.birthYear не існує;
  • x = x замість this.x = x у методі з однойменним параметром;
  • відкрита var-властивість там, де вистачило б private set;
  • у власному setter-і написали target = value замість field = value — нескінченна рекурсія.
