5. Типові помилки

  • очікували копію від val b = a — а змінили спільний об’єкт;
  • a == b для звичайного класу: false, хоча значення однакові;
  • спроба створити об’єкт класу з private constructor поза його companion;
  • плутанина Person::greet (потрібен об’єкт-аргумент) з olya::greet (об’єкт уже є).
