Конструктор і блок init

Як задавати початкові значення при створенні об’єкта.

1. Первинний конструктор

Писати a.x = 3; a.y = 4 після кожного створення незручно — легко забути ініціалізувати. Значення краще передавати при створенні. Для цього первинний конструктор (primary constructor) пишуть у дужках одразу після імені класу:

class Point(val x: Int, val y: Int)

val p = Point(3, 4)
println("${p.x}, ${p.y}")   // 3, 4

Слова val/var перед параметром конструктора одночасно оголошують властивість з тим самим іменем. Тіло класу { } не обов’язкове, якщо воно порожнє.

Параметри конструктора — це звичайні параметри функції, тож працюють значення за замовчуванням та іменовані аргументи з модуля «Функції»:

class Rectangle(val width: Int, val height: Int, val label: String = "rect")

val r1 = Rectangle(2, 3)
val r2 = Rectangle(height = 5, width = 1, label = "wide")
Скільки властивостей має клас Rectangle(val width: Int, val height: Int, val label: String = "rect")?

2. Параметр без val/var — не властивість

Якщо перед параметром немає val чи var, це лише параметр: його видно під час створення об’єкта, але після цього він зникає.

class Person(val name: String, birthYear: Int) {
    val age = 2026 - birthYear    // birthYear можна використати в ініціалізаторі
}

val person = Person("Оля", 2000)
println(person.age)         // 26
// println(person.birthYear)   // помилка: такої властивості немає

3. Блок init: перевірка при створенні

Блок init виконується щоразу при створенні об’єкта, відразу після первинного конструктора. Зручно для перевірки вхідних даних: функція require(умова) { "повідомлення" } (ви вже бачили її в Matrix) зупиняє програму, якщо умова хибна. Докладно про винятки — у модулі 9.

class Rectangle(val width: Int, val height: Int) {
    init {
        require(width > 0 && height > 0) { "Сторони мають бути додатними: ${width}x$height" }
    }
}

Rectangle(2, 3)    // гаразд
Rectangle(0, 5)    // IllegalArgumentException: Сторони мають бути додатними: 0x5

Це головна мета init: об’єкт ніколи не опиниться у «зламаному» стані — або створюється коректним, або не створюється взагалі.

4. Додатковий конструктор

Іноді потрібен ще один спосіб створення. Додатковий конструктор (secondary constructor) оголошується ключовим словом constructor і обов’язково викликає первинний через this(…):

class Point(val x: Int, val y: Int) {
    constructor() : this(0, 0)      // Point() — початок координат
}
Додаткові конструктори в Kotlin трапляються рідко: майже завжди достатньо значень за замовчуванням. Якщо ж потрібно створювати об’єкти «іменованими способами» (fromFahrenheit(…)), використовують фабричні методи — урок «Companion object».

5. Практика

Напишіть клас Student(val name: String, val grade: Int) з перевіркою grade in 1..12 у init. Створіть коректного студента й спробуйте створити студента з оцінкою 15. Додайте значення за замовчуванням grade = 1 і створіть студента лише з іменем.

class Point(val x: Int, val y: Int) {
    constructor() : this(0, 0)      // додатковий конструктор
}

class Rectangle(val width: Int, val height: Int, val label: String = "rect") {
    init {
        require(width > 0 && height > 0) { "Сторони мають бути додатними: ${width}x$height" }
        println("Створено $label ${width}x$height")
    }
}

class Person(val name: String, birthYear: Int) {
    val age = 2026 - birthYear      // birthYear — лише параметр, не властивість
}

fun main() {
    val p = Point(3, 4)
    println("${p.x}, ${p.y}")                  // 3, 4
    val origin = Point()
    println("${origin.x}, ${origin.y}")        // 0, 0

    val r1 = Rectangle(2, 3)                   // Створено rect 2x3
    val r2 = Rectangle(height = 5, width = 1, label = "wide")   // Створено wide 1x5
    println(r1.width * r2.height)              // 10

    val person = Person("Оля", 2000)
    println("${person.name}, ${person.age}")   // Оля, 26
    // println(person.birthYear)               // розкоментуйте: помилка

    // val bad = Rectangle(0, 5)               // розкоментуйте: IllegalArgumentException
}
