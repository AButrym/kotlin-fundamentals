Клас і об’єкт

Тип із власними полями: опис (клас) і конкретні екземпляри (об’єкти).

Ви вже зустрічали клас. У модулі «Цикли та масиви» ми писали Matrix — це був клас. Тоді ми користувалися ним «за шаблоном»; тепер вивчаємо класи систематично, з нуля.

1. Навіщо потрібні класи

Точка на площині — це два числа, що завжди йдуть разом: x і y. Якщо тримати їх як окремі змінні, для кожної точки доводиться вигадувати пари імен (x1, y1, x2, y2…), а передати точку у функцію — це вже два параметри. Клас дозволяє описати новий тип, що об’єднує дані.

  • Клас — опис: які дані містить тип і що з ними можна робити («креслення»).
  • Об’єкт (екземпляр, object / instance) — конкретна «річ», створена за цим описом. З одного класу можна створити скільки завгодно об’єктів.

2. Оголошення класу та створення об’єкта

class Point {
    var x = 0
    var y = 0
}

fun main() {
    val a = Point()      // створення об’єкта: ім’я класу + дужки
    a.x = 3              // доступ до властивості через крапку
    a.y = 4
    println("(${a.x}, ${a.y})")   // (3, 4)
}
  • var x = 0 усередині класу — це властивість (property): змінна, що належить кожному об’єктові окремо. Тип Int виводиться з початкового значення, як і для звичайних змінних.
  • Point() — виклик конструктора. У Kotlin немає слова new.
  • a.x — читання, a.x = 3 — запис властивості об’єкта a.
  • Назви класів пишуть з великої літери (Point), змінних і властивостей — з малої.
Яке значення побачимо: val b = Point() і одразу println(b.x)?

3. Об’єкти незалежні

Кожен об’єкт має власний набір значень властивостей:

val a = Point()
a.x = 3
val b = Point()
b.x = 10
println(a.x)   // 3 — зміна b не торкнулася a
println(b.x)   // 10

Властивості бувають val і var, як і звичайні змінні: val dimension = 2 у класі не можна змінити після створення, а var — можна.

Ще раз про val. val a = Point() забороняє лише присвоїти змінній a інший об’єкт. Змінювати властивості-var самого об’єкта (a.x = 3) можна. Чому так — в уроці «Посилання та рівність об’єктів».

4. Практика

Опишіть клас Book із властивостями title (String, початкове значення "") та pages (Int, початкове 0). Створіть два об’єкти, заповніть їх і виведіть "<назва>: <кількість> стор.". Спробуйте змінити val-властивість — подивіться, яку помилку видасть компілятор.

class Point {
    var x = 0
    var y = 0
    val dimension = 2      // val: після ініціалізації незмінна
}

fun main() {
    val a = Point()
    a.x = 3
    a.y = 4

    val b = Point()
    b.x = 10

    println("a = (${a.x}, ${a.y})")   // a = (3, 4)
    println("b = (${b.x}, ${b.y})")   // b = (10, 0)

    b.y = a.y * 2
    println("b = (${b.x}, ${b.y})")   // b = (10, 8)
    println("a = (${a.x}, ${a.y})")   // a = (3, 4) — a не змінився

    println(a.dimension)              // 2
    // a.dimension = 3                // розкоментуйте: помилка (val)
}
