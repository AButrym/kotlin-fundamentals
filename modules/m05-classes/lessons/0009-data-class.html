data class

Клас-контейнер для даних: toString, ==, copy і деструктуризація — безкоштовно.

1. Проблема: «голий» клас-контейнер

Багато класів існують лише щоб зберігати кілька значень разом: точка, покупка, студент. Для звичайного класу ми щоразу самі писали toString, а == порівнювало б посилання (урок 5). Для таких класів Kotlin пропонує data class:

class PlainPoint(val x: Int, val y: Int)
data class Point(val x: Int, val y: Int)

println(PlainPoint(1, 2) == PlainPoint(1, 2))   // false
println(Point(1, 2) == Point(1, 2))             // true
println(PlainPoint(1, 2))                       // PlainPoint@6d06d69c
println(Point(1, 2))                            // Point(x=1, y=2)

Достатньо додати слово data перед class — і компілятор сам створює корисні методи за властивостями первинного конструктора. Саме такі класи (data class Purchase(...)) ви зустрінете в модулі «Колекції».

2. Що генерується

МетодЩо робить
toString()красивий текст: Point(x=1, y=2)
equals() / hashCode()== порівнює значення властивостей; hashCode — «числовий відбиток» значень, потрібний множинам і словникам (Колекції)
copy(...)нова копія із зміною лише вказаних властивостей
component1(), component2(), …основа для деструктуризації

Вимоги: у первинному конструкторі має бути хоча б один параметр, і кожен із них — val або var. Рекомендація: робіть їх val — тоді об’єкт незмінний, і його безпечно передавати будь-куди.

val p = Point(1, 2); val q = p.copy(y = 5). Що виведе println(q)?

3. copy: «змінити» незмінний об’єкт

Якщо властивості val, змінити їх не можна. Замість цього створюють нову копію з потрібними змінами — оригінал лишається цілим:

val p = Point(1, 2)
val moved = p.copy(x = 10)
println(moved)     // Point(x=10, y=2)
println(p)         // Point(x=1, y=2) — не змінився

4. Деструктуризація

Об’єкт data class можна розкласти на змінні за порядком властивостей у конструкторі — деструктуризація, яку ви бачили з withIndex():

val (x, y) = Point(1, 2)
println("$x, $y")      // 1, 2

Це працює завдяки згенерованим component1(), component2(). Порядок важливий: перша змінна отримує першу властивість конструктора.

5. Тільки властивості конструктора

Усі згенеровані методи враховують лише властивості первинного конструктора. Властивості, оголошені в тілі класу, ігноруються:

data class User(val name: String, val age: Int) {
    var note: String = ""        // у тілі — не бере участі
}

val u1 = User("Оля", 20); u1.note = "A"
val u2 = User("Оля", 20); u2.note = "B"
println(u1 == u2)                // true — note не порівнюється
println(u1)                      // User(name=Оля, age=20)
println(u1.copy().note)          // "" — note у копію не потрапляє
Не кладіть у тіло data-класу властивості, від яких залежить «ідентичність» об’єкта: порівняння та копіювання їх проігнорують.

User("Оля", 20) із note = "A" і User("Оля", 20) із note = "B" — що дасть ==? (note оголошено в тілі класу)

6. Практика

Опишіть data class Purchase(val item: String, val price: Int, val category: String). Створіть два однакових за змістом об’єкти й переконайтеся, що вони ==. Зробіть копію з іншою ціною через copy(price = …), а потім розкладіть її на три змінні та виведіть.

class PlainPoint(val x: Int, val y: Int)

data class Point(val x: Int, val y: Int)

data class Purchase(val item: String, val price: Int, val category: String)

data class User(val name: String, val age: Int) {
    var note: String = ""              // не входить у конструктор — ігнорується згенерованими методами
}

fun main() {
    val a = PlainPoint(1, 2)
    val b = PlainPoint(1, 2)
    println(a == b)                    // false
    println(a)                         // PlainPoint@… (адреса)

    val p = Point(1, 2)
    val q = Point(1, 2)
    println(p == q)                    // true — порівнюються значення властивостей
    println(p)                         // Point(x=1, y=2)
    println(p.hashCode() == q.hashCode())   // true

    val moved = p.copy(x = 10)         // нова копія з однією зміною
    println(moved)                     // Point(x=10, y=2)
    println(p)                         // Point(x=1, y=2) — оригінал не змінився

    val (x, y) = p                     // деструктуризація
    println("$x, $y")                  // 1, 2

    val purchase = Purchase("Хліб", 30, "їжа")
    println(purchase)                  // Purchase(item=Хліб, price=30, category=їжа)

    val u1 = User("Оля", 20)
    u1.note = "A"
    val u2 = User("Оля", 20)
    u2.note = "B"
    println(u1 == u2)                  // true — note не враховується
    println(u1)                        // User(name=Оля, age=20)
    println(u1.copy().note.isEmpty())  // true — note у копію не потрапляє
}
