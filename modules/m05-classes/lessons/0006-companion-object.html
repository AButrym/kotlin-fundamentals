Companion object: константи та фабрики

Константи, фабричні методи та спільний лічильник — те, що належить класу загалом, а не окремому об’єкту.

1. Що належить класу, а не об’єкту

Властивості й методи, які ми писали досі, «живуть» в кожному об’єкті окремо. Але іноді потрібне те, що спільне для всього класу:

  • константа (MIN_DEPOSIT = 10);
  • лічильник виданих номерів (nextId);
  • «іменований спосіб створення» (Temperature.ofFahrenheit(212.0)).

У Kotlin для цього є companion object — блок усередині класу, члени якого викликають через ім’я класу, без створення об’єкта (у Java це роль static).

class Account(val id: Int, val owner: String) {
    companion object {
        const val MIN_DEPOSIT = 10
    }
}

println(Account.MIN_DEPOSIT)    // 10
  • У класі може бути лише один companion object.
  • const val — константа, значення якої відоме на етапі компіляції (числа, Boolean, String). Те саме const val SIZE = 4, яке ви писали в «П’ятнашках» на рівні файлу.
  • Усередині класу до членів companion звертаються просто за іменем: if (amount < MIN_DEPOSIT).

2. Фабричні методи

Конструктор завжди має ім’я класу й не може пояснити, що саме ми передаємо. Порівняйте: Temperature(212.0) — це градуси Цельсія чи Фаренгейта? Рішення: сховати конструктор (private constructor) і створювати об’єкти фабричними методами з companion:

class Temperature private constructor(val celsius: Double) {
    companion object {
        fun ofCelsius(c: Double): Temperature = Temperature(c)
        fun ofFahrenheit(f: Double): Temperature = Temperature((f - 32) * 5 / 9)
    }

    override fun toString(): String = "%.1f °C".format(celsius)
}

println(Temperature.ofFahrenheit(212.0))   // 100.0 °C
// Temperature(5.0)                         // помилка: конструктор private

Companion — частина класу, тому йому дозволено викликати приватний конструктор. Ззовні об’єкт можна створити тільки через фабрики.

Дрібниця: "%.1f".format(…) залежить від локалі системи — у Playground буде 100.0, а на комп’ютері з українською локаллю — 100,0.

3. Спільний лічильник

Властивість у companion існує в єдиному екземплярі на весь клас — ідеально для генерації унікальних номерів:

class Account private constructor(val id: Int, val owner: String) {
    companion object {
        private var nextId = 1                 // спільний для всіх рахунків

        fun open(owner: String): Account {
            val account = Account(nextId, owner)
            nextId++
            return account
        }
    }
}

val a = Account.open("Оля")      // id = 1
val b = Account.open("Іван")     // id = 2

Кожен об’єкт має власне owner, але nextId — один на всіх.

Це лише мінімум. Companion може мати ім’я, реалізовувати інтерфейси й багато іншого — див. companion: деталі. Окремі «одноосібні» об’єкти без класу-власника — оголошення object; усе це — модуль 7.

4. Практика

Створіть клас Student із private constructor(val name: String, val id: Int) та фабрикою Student.enroll(name), що видає зростаючі id, починаючи з 1000. Додайте const val MAX_NAME = 20 і обрізайте імена довші за 20 символів методом name.take(MAX_NAME).

class Account private constructor(val id: Int, val owner: String) {
    var balance: Int = 0
        private set

    fun deposit(amount: Int): Boolean {
        if (amount < MIN_DEPOSIT) return false
        balance += amount
        return true
    }

    companion object {
        const val MIN_DEPOSIT = 10
        private var nextId = 1         // один на весь клас, а не на кожен об’єкт

        fun open(owner: String): Account {
            val account = Account(nextId, owner)
            nextId++
            return account
        }
    }
}

class Temperature private constructor(val celsius: Double) {
    companion object {
        fun ofCelsius(c: Double): Temperature = Temperature(c)
        fun ofFahrenheit(f: Double): Temperature = Temperature((f - 32) * 5 / 9)
    }

    override fun toString(): String = "%.1f °C".format(celsius)
}

fun main() {
    val a = Account.open("Оля")
    val b = Account.open("Іван")
    println("${a.id} ${a.owner}")      // 1 Оля
    println("${b.id} ${b.owner}")      // 2 Іван

    println(a.deposit(5))              // false
    println(a.deposit(50))             // true
    println(a.balance)                 // 50
    println(Account.MIN_DEPOSIT)       // 10
    // val c = Account(3, "Хтось")     // розкоментуйте: конструктор private

    println(Temperature.ofFahrenheit(212.0))   // 100.0 °C
    println(Temperature.ofCelsius(36.6))       // 36.6 °C
}
