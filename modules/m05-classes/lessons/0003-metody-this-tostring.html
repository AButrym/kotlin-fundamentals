Методи, this і toString

Поведінка об’єкта: функції всередині класу, ключове слово this та текстове подання.

1. Метод — функція всередині класу

Метод — це функція, оголошена в тілі класу. Вона виконується для конкретного об’єкта і напряму бачить його властивості. Усе, що ви знаєте про функції (параметри, значення за замовчуванням, return, функції-вирази), працює й для методів.

class Counter {
    var value = 0

    fun increment() {
        value++              // value — властивість «цього» об’єкта
    }

    fun add(n: Int) {
        value += n
    }
}

val c = Counter()
c.increment()
c.increment()
c.add(5)
println(c.value)    // 7

Метод викликають через крапку на об’єкті: c.increment(). Два різні лічильники мають різні value.

2. Методи, що повертають результат

import kotlin.math.sqrt

class Point(val x: Int, val y: Int) {
    fun distanceTo(other: Point): Double {
        val dx = (x - other.x).toDouble()
        val dy = (y - other.y).toDouble()
        return sqrt(dx * dx + dy * dy)
    }

    fun isOrigin(): Boolean = x == 0 && y == 0

    fun shifted(dx: Int, dy: Int): Point = Point(x + dx, y + dy)   // новий об’єкт
}

println(Point(0, 0).distanceTo(Point(3, 4)))   // 5.0

Усередині методу x і y — властивості «поточного» об’єкта, а other.x — іншого. Метод shifted нічого не змінює, а повертає новий об’єкт; такий стиль («незмінні» об’єкти з val) безпечніший, ми ще до нього повернемось.

Метод isOrigin() викликано на Point(0, 5). Що він поверне? (true/false)

3. this

Усередині методу є прихований «параметр» — this: посилання на об’єкт, для якого метод викликано. Зазвичай писати його не треба, але він потрібен, коли ім’я параметра збігається з іменем властивості:

class Cursor(var x: Int, var y: Int) {
    fun moveTo(x: Int, y: Int) {
        this.x = x          // властивість = параметр
        this.y = y
    }
}

Без this запис x = x присвоїв би параметр самому собі — властивість не змінилась би.

4. toString: як об’єкт виглядає у println

Якщо вивести об’єкт «як є», Kotlin не знає, як його показати:

class Dot(val x: Int)
println(Dot(1))      // Dot@1b6d3586 — ім’я класу й адреса в пам’яті (число щоразу інше)

Щоб println та рядкові шаблони показували щось осмислене, у класі оголошують спеціальний метод toString:

class Point(val x: Int, val y: Int) {
    override fun toString(): String = "($x, $y)"
}

val p = Point(3, 4)
println(p)                  // (3, 4)
println("Точка p = $p")     // Точка p = (3, 4)
Слово override перед fun toString поки що пишіть як обов’язковий шаблон: метод toString уже існує в кожного об’єкта, і ми його «перевизначаємо». Як це працює — в уроці «Успадкування» (термін override).

Навіщо в методі moveTo(x: Int, y: Int) пишуть this.x = x?

5. Практика

Додайте до класу Point метод fun scaled(k: Int): Point (множить обидві координати на k) і override fun toString(). Виведіть Point(2, 3).scaled(10). Потім у класі Counter напишіть fun reset(), що скидає значення, і метод fun isZero(): Boolean.

import kotlin.math.sqrt

class Counter {
    var value = 0

    fun increment() {
        value++
    }

    fun add(n: Int) {
        value += n
    }

    fun reset() {
        value = 0
    }
}

class Cursor(var x: Int, var y: Int) {
    fun moveTo(x: Int, y: Int) {      // параметри «затіняють» властивості
        this.x = x
        this.y = y
    }
}

class Dot(val x: Int)                 // без toString

class Point(val x: Int, val y: Int) {
    fun distanceTo(other: Point): Double {
        val dx = (x - other.x).toDouble()
        val dy = (y - other.y).toDouble()
        return sqrt(dx * dx + dy * dy)
    }

    fun isOrigin(): Boolean = x == 0 && y == 0

    fun shifted(dx: Int, dy: Int): Point = Point(x + dx, y + dy)

    override fun toString(): String = "($x, $y)"
}

fun main() {
    val c = Counter()
    c.increment()
    c.increment()
    c.add(5)
    println(c.value)                  // 7
    c.reset()
    println(c.value)                  // 0

    val cur = Cursor(1, 1)
    cur.moveTo(5, 6)
    println("${cur.x}, ${cur.y}")     // 5, 6

    println(Dot(1))                   // Dot@… (адреса в пам’яті; щоразу різна)

    val a = Point(0, 0)
    val b = Point(3, 4)
    println(a.distanceTo(b))          // 5.0
    println(a.isOrigin())             // true
    println(b)                        // (3, 4)
    println(b.shifted(1, 1))          // (4, 5)
    println("Точка b = $b")           // Точка b = (3, 4)
}
