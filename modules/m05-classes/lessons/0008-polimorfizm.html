Поліморфізм, is і smart cast

Один тип змінної — різні справжні об’єкти. Перевірка типу через is.

1. Змінна базового типу тримає нащадка

Оскільки собака — тварина, об’єкт Dog можна покласти в змінну типу Animal. Виклик методу виконається за справжнім типом об’єкта, а не за типом змінної — це поліморфізм:

val pet: Animal = Dog("Бім")
println(pet.sound())      // Гав — версія з Dog

2. Колекція різних об’єктів

Найкорисніше: працювати з різними об’єктами однаково. Функція не знає, які саме тварини в списку, і їй це не потрібно:

class Cow(name: String) : Animal(name) {
    override fun sound() = "Му"
}

fun chorus(animals: List<Animal>) {
    for (a in animals) {
        println("${a.name}: ${a.sound()}")
    }
}

val zoo: List<Animal> = listOf(Dog("Рекс"), Cat("Мурка"), Cow("Зорька"))
chorus(zoo)
// Рекс: Гав
// Мурка: Няв
// Зорька: Му
List<Animal> — «список тварин»; списки докладно вивчаються в модулі «Колекції», а запис <Animal> у кутових дужках (generics) — ще пізніше. Поки читайте це як «список, де кожен елемент — Animal або його нащадок».

Додайте новий клас Bird — і chorus працюватиме з ним без жодних змін. Це головна перевага: код залежить від базового типу, а не від списку конкретних нащадків.

val pet: Animal = Cat("Мурка"). Що поверне pet.sound(), якщо в Cat перевизначено sound() як "Няв"?

3. Видно лише те, що є в типі змінної

val pet: Animal = Dog("Бім")
pet.fetch()     // помилка: в Animal немає методу fetch

Компілятор перевіряє тип змінної: Animal не гарантує наявності fetch(), адже у списку може бути й Cat. Якщо метод потрібен саме для Dog, треба спершу перевірити тип.

4. is і smart cast

Оператор is перевіряє справжній тип об’єкта. Усередині перевіреної гілки Kotlin сам «звужує» тип змінної — smart cast (приведення типу вручну не потрібне):

fun playWith(a: Animal): String {
    if (a is Dog) {
        return a.fetch()        // тут a вже сприймається як Dog
    }
    return "${a.name} не вміє приносити м’яч"
}

fun kind(a: Animal): String = when (a) {
    is Dog -> "собака"
    is Cat -> "кіт"
    else -> "інша тварина"
}

is також працює всередині when (пригадайте when). Для when над відкритим класом else обов’язкове — адже нащадків може бути скільки завгодно.

Що станеться при val pet: Animal = Dog("Бім"); println(pet.fetch())?

5. Коли is, а коли поліморфізм

Перевірки is дозволяють дізнатися справжній тип, але якщо вони розповзаються по коду, кожен новий нащадок вимагатиме змінювати всі такі when. Надійніше робити так: загальну поведінку оголошувати методом базового класу та перевизначати в нащадках (як sound()), а is залишати для рідкісних випадків. Для замкненого переліку варіантів існують enum і sealed-ієрархії — вони з’являться в пізніших модулях.

6. Практика

Додайте клас Bird зі звуком «Цвірінь» і перевірте, що chorus не потребує змін. Напишіть функцію fun countDogs(animals: List<Animal>): Int, що рахує собак через is (цикл + лічильник).

open class Animal(val name: String) {
    open fun sound(): String = "..."
}

class Dog(name: String) : Animal(name) {
    override fun sound() = "Гав"

    fun fetch() = "$name приносить м’яч"
}

class Cat(name: String) : Animal(name) {
    override fun sound() = "Няв"
}

class Cow(name: String) : Animal(name) {
    override fun sound() = "Му"
}

fun chorus(animals: List<Animal>) {
    for (a in animals) {
        println("${a.name}: ${a.sound()}")    // версія sound() обирається за справжнім типом
    }
}

fun playWith(a: Animal): String {
    if (a is Dog) {
        return a.fetch()                      // тут a автоматично «стає» Dog (smart cast)
    }
    return "${a.name} не вміє приносити м’яч"
}

fun kind(a: Animal): String = when (a) {
    is Dog -> "собака"
    is Cat -> "кіт"
    else -> "інша тварина"
}

fun main() {
    val zoo: List<Animal> = listOf(Dog("Рекс"), Cat("Мурка"), Cow("Зорька"))
    chorus(zoo)
    // Рекс: Гав
    // Мурка: Няв
    // Зорька: Му

    for (a in zoo) println(playWith(a))
    // Рекс приносить м’яч
    // Мурка не вміє приносити м’яч
    // Зорька не вміє приносити м’яч

    for (a in zoo) println(kind(a))           // собака, кіт, інша тварина

    val pet: Animal = Dog("Бім")
    println(pet.sound())                      // Гав
    // println(pet.fetch())                   // розкоментуйте: помилка — у типу Animal немає fetch
    if (pet is Dog) println(pet.fetch())      // Бім приносить м’яч
}
