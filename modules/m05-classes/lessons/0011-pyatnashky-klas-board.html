Підсумок: «П’ятнашки» як клас

Збираємо все разом: гра «П’ятнашки» тепер є класом із фабриками, методами та приватним станом.

1. Постановка

У модулі «Цикли та масиви» ми будували поле «П’ятнашок» функціями над масивом. Тепер оформимо його класом Board: стан (поле) прихований, ззовні лише безпечні операції.

  • Board.solved() — розв’язане поле;
  • Board.scrambled(moves) — випадкове, але завжди розв’язуване;
  • isSolved — чи плитки стоять по порядку;
  • move(row, col) — зсунути плитку в порожню клітинку, якщо вона сусідня;
  • toString() — гарний друк поля.

Для зберігання поля використаємо Matrix із уроку 11 модуля 3 — без жодних змін (cells[r, c]).

2. Каркас класу

class Board private constructor(private val cells: Matrix) {

    companion object {
        const val SIZE = 4
        const val BLANK = 16
        private val DR = intArrayOf(-1, 1, 0, 0)    // зсуви по рядку: вгору, вниз, …
        private val DC = intArrayOf(0, 0, -1, 1)    // зсуви по стовпцю: …, ліворуч, праворуч

        fun solved(): Board {
            val m = Matrix(SIZE, SIZE)
            for (i in 0 until SIZE * SIZE) {
                m[i / SIZE, i % SIZE] = i + 1
            }
            return Board(m)
        }
        // scrambled(...) — нижче
    }
    // властивості й методи — нижче
}
  • private constructor + фабрики в companion (урок 6): поле можна створити лише розв’язаним або перемішаним законним шляхом.
  • cells — private: ззовні матрицю не зіпсувати (урок 4).

3. Властивість, метод, toString

    val isSolved: Boolean            // обчислювана властивість (урок 4)
        get() {
            for (i in 0 until SIZE * SIZE) {
                if (cells[i / SIZE, i % SIZE] != i + 1) return false
            }
            return true
        }

    fun move(row: Int, col: Int): Boolean {      // метод (урок 3)
        for (d in 0 until 4) {
            val r = row + DR[d]
            val c = col + DC[d]
            if (r in 0 until SIZE && c in 0 until SIZE && cells[r, c] == BLANK) {
                cells[r, c] = cells[row, col]
                cells[row, col] = BLANK
                return true
            }
        }
        return false
    }

    override fun toString(): String {            // урок 3 і 7
        val sb = StringBuilder()
        for (r in 0 until SIZE) {
            for (c in 0 until SIZE) {
                val v = cells[r, c]
                val text = if (v == BLANK) "·" else v.toString()
                sb.append(text.padStart(3))
            }
            sb.append('\n')
        }
        return sb.toString()
    }

move перевіряє чотирьох сусідів плитки: якщо один із них — порожня клітинка, міняє їх місцями й повертає true; якщо ні — поле не змінюється і результат false. StringBuilder — готовий клас стандартної бібліотеки для побудови тексту частинами.

4. Чому scrambled завжди розв’язуване

У модулі 3 ми перемішували плитки й перевіряли парність інверсій. Тут інший підхід: стартуємо з розв’язаного поля й робимо лише законні ходи — кожен хід зберігає розв’язуваність (це і є інваріант з уроку про інверсії), тож нерозв’язного поля вийти не може:

        fun scrambled(moves: Int): Board {       // у companion object
            val board = solved()
            var blankRow = SIZE - 1
            var blankCol = SIZE - 1
            repeat(moves) {
                val d = Random.nextInt(4)
                val r = blankRow + DR[d]
                val c = blankCol + DC[d]
                if (r in 0 until SIZE && c in 0 until SIZE) {
                    board.move(r, c)             // плитка (r, c) їде в порожню клітинку
                    blankRow = r
                    blankCol = c
                }
            }
            return board
        }

Потрібен import kotlin.random.Random на початку файла. Змінні blankRow/blankCol — позиція порожньої клітинки: після зсуву плитки вона переходить туди, де плитка стояла.

Чому Board.scrambled(...) не може дати нерозв’язне поле?

6. Практика

Додайте var moves: Int = 0 із private set — лічильник успішних ходів (збільшуйте в move, коли повертаєте true). Потім у main зіграйте кілька ходів вручну (move(3, 2), move(3, 1), …) і виведіть кількість ходів та isSolved.

import kotlin.random.Random

// Matrix — без змін із модуля «Цикли та масиви» (урок 11)
class Matrix(val rows: Int, val cols: Int) {
    private val data = IntArray(rows * cols)

    private fun checkBounds(row: Int, col: Int) {
        require(row in 0 until rows && col in 0 until cols) {
            "($row, $col) поза межами матриці ${rows}x$cols"
        }
    }

    operator fun get(row: Int, col: Int): Int {
        checkBounds(row, col)
        return data[row * cols + col]
    }

    operator fun set(row: Int, col: Int, value: Int) {
        checkBounds(row, col)
        data[row * cols + col] = value
    }
}

class Board private constructor(private val cells: Matrix) {

    companion object {
        const val SIZE = 4
        const val BLANK = 16
        private val DR = intArrayOf(-1, 1, 0, 0)    // зсуви по рядку для 4 напрямів
        private val DC = intArrayOf(0, 0, -1, 1)    // зсуви по стовпцю

        fun solved(): Board {
            val m = Matrix(SIZE, SIZE)
            for (i in 0 until SIZE * SIZE) {
                m[i / SIZE, i % SIZE] = i + 1
            }
            return Board(m)
        }

        // Випадкові ЛЕГАЛЬНІ ходи з розв’язаного поля → поле гарантовано розв’язуване
        fun scrambled(moves: Int): Board {
            val board = solved()
            var blankRow = SIZE - 1
            var blankCol = SIZE - 1
            repeat(moves) {
                val d = Random.nextInt(4)
                val r = blankRow + DR[d]
                val c = blankCol + DC[d]
                if (r in 0 until SIZE && c in 0 until SIZE) {
                    board.move(r, c)          // плитка (r, c) їде в порожню клітинку
                    blankRow = r
                    blankCol = c
                }
            }
            return board
        }
    }

    fun tile(row: Int, col: Int): Int = cells[row, col]

    val isSolved: Boolean
        get() {
            for (i in 0 until SIZE * SIZE) {
                if (cells[i / SIZE, i % SIZE] != i + 1) return false
            }
            return true
        }

    // Пересуває плитку (row, col) у порожню клітинку, якщо вони сусідні
    fun move(row: Int, col: Int): Boolean {
        for (d in 0 until 4) {
            val r = row + DR[d]
            val c = col + DC[d]
            if (r in 0 until SIZE && c in 0 until SIZE && cells[r, c] == BLANK) {
                cells[r, c] = cells[row, col]
                cells[row, col] = BLANK
                return true
            }
        }
        return false
    }

    override fun toString(): String {
        val sb = StringBuilder()
        for (r in 0 until SIZE) {
            for (c in 0 until SIZE) {
                val v = cells[r, c]
                val text = if (v == BLANK) "·" else v.toString()
                sb.append(text.padStart(3))
            }
            sb.append('\n')
        }
        return sb.toString()
    }
}

fun main() {
    val board = Board.solved()
    print(board)
    println(board.isSolved)        // true
    println(board.move(0, 0))      // false — плитка 1 не сусідить із порожньою
    println(board.move(3, 2))      // true  — плитка 15 їде вправо
    println(board.isSolved)        // false
    println(board.tile(3, 3))      // 15
    print(board)

    println("--- Перемішане поле ---")
    print(Board.scrambled(50))     // випадкове, але розв’язуване
}
