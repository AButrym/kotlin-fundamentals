Посилання та рівність об’єктів

Змінна не містить об’єкт — вона вказує на нього. Звідси спільні об’єкти та два види рівності.

1. Змінна зберігає посилання

Для Int чи Boolean присвоєння копіює значення. Для об’єктів усе інакше: змінна зберігає посилання на об’єкт, і присвоєння копіює лише посилання. Ви вже бачили це з масивами (аліасинг) — для об’єктів класів діє той самий закон.

class Point(var x: Int, var y: Int)

val a = Point(1, 2)
val b = a            // не копія, а друге посилання на той самий об’єкт
b.x = 100
println(a.x)         // 100 — об’єкт один, змінили його через b
val a = Point(1, 2); val b = a; b.x = 9 — що виведе println(a.x)?

2. Об’єкти у функціях

Так само, коли об’єкт передають у функцію, передається посилання, і функція може його змінити:

fun moveRight(p: Point) {
    p.x += 1
}

moveRight(a)
println(a.x)         // змінився й назовні

Це зручно (не копіюємо великі структури), але й небезпечно: «хтось інший» теж тримає посилання на цей самий об’єкт. Саме тому корисні val-властивості й приватні сеттери з уроку 4.

3. val і посилання

val a = Point(1, 2) означає: змінна a завжди вказуватиме на цей об’єкт (a = Point(0, 0) — помилка). Але вміст об’єкта змінювати можна, якщо його властивості — var. Хочете, щоб і вміст не змінювався — робіть властивості val.

4. Два види рівності: == і ===

У Kotlin є два оператори порівняння об’єктів (рівність):

ОператорПитанняДля звичайного класу
===Це той самий об’єкт (однакове посилання)?завжди працює так
==Об’єкти «рівні за змістом»?за замовчуванням — теж порівнює посилання
val c = Point(1, 2)
val d = Point(1, 2)
println(c == d)      // false — різні об’єкти, хоч і однакові за змістом
println(c === d)     // false
val e = c
println(c === e)     // true — одне й те саме посилання

Тобто для власного класу == не порівнює властивості «сам собою». Щоб Point(1, 2) == Point(1, 2) було true, потрібен метод equals (і узгоджений hashCode) — вручну їх писати складно й легко помилитися, тому в Kotlin є готове рішення — data class. До нього ми ще дійдемо.

Що виведе println(Point(1, 2) == Point(1, 2)) для звичайного (не data) класу Point?

5. Пастка: один об’єкт у масиві N разів

Пригадайте проблему з матрицею з уроку «Вкладені масиви». З об’єктами повторюється те саме:

val shared = Point(0, 0)
val bad = Array(3) { shared }          // три посилання на ОДИН об’єкт
bad[0].x = 5
println(bad[2].x)                      // 5!

val good = Array(3) { Point(0, 0) }    // лямбда щоразу створює новий об’єкт
good[0].x = 5
println(good[2].x)                     // 0
