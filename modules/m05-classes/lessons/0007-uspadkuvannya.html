Успадкування: open, override, super

Як один клас розширює інший: open, наслідування конструктора, override і super.

1. Навіщо успадкування

Собака й кіт — різні типи, але обидва — тварини: мають ім’я й видають звуки. Копіювати спільне в обидва класи — це дублювання. Успадкування (inheritance) дозволяє описати спільне в базовому класі, а в похідних додати лише відмінності. Критерій: похідний клас — різновид базового («собака — це тварина»).

2. open і наслідування конструктора

Класи в Kotlin за замовчуванням закриті (final): успадкувати їх не можна. Щоб дозволити, базовий клас позначають open. Похідний клас після двокрапки викликає конструктор базового:

open class Animal(val name: String) {
    open fun sound(): String = "..."

    fun describe(): String = "$name каже ${sound()}"
}

class Dog(name: String) : Animal(name) {
    override fun sound(): String = "Гав"

    fun fetch(): String = "$name приносить м’яч"
}

val d = Dog("Рекс")
println(d.describe())     // Рекс каже Гав
println(d.fetch())        // Рекс приносить м’яч
  • class Dog(name: String) : Animal(name) — Dog приймає name і передає його конструктору Animal. Властивість name оголошена один раз — у базовому класі.
  • Dog отримує з Animal усе, крім private: властивість name, метод describe() (він не open, але успадковується; просто його не можна перевизначити).

3. override: змінити поведінку

Метод базового класу можна перевизначити лише якщо він позначений open, і в похідному класі ставлять override:

  • open fun sound() — «дозволено перевизначати»;
  • override fun sound() — «перевизначаю»;
  • метод без open (як describe) перевизначити не можна — він final.

Зверніть увагу: describe() (у базовому класі) викликає sound() — і для Dog виконується версія Dog.sound(). Базовий код «не знає», чий саме метод запуститься; це основа поліморфізму (наступний урок).

Яка версія sound() виконається в Dog("Рекс").describe(): з Animal чи з Dog?

4. super і спільний предок Any

Усередині перевизначеного методу можна викликати версію базового класу через super:

class Cat(name: String) : Animal(name) {
    override fun sound(): String = "Няв"
    override fun toString(): String = "Cat($name) → " + super.toString()
}

А звідки взявся super.toString(), якщо в Animal ми його не писали? Усі класи Kotlin неявно успадковують спільний корінь Any, у якому вже є toString(), equals() і hashCode(). Тож override fun toString() з уроку 3 — це саме перевизначення методу з Any. Тепер ясно, чому println(Dot(1)) друкував Dot@…: це версія з Any.

Якщо в об’єкта «раптом» є метод, якого ви не писали, — шукайте його в базовому класі, зокрема в Any.

Що станеться, якщо спробувати успадкувати клас, не позначений open?

5. Що відкладаємо

У нашому Animal метод sound() повертає безглузде "..." — тварини «взагалі» не існує, є лише конкретні види. Щоб заборонити створювати «абстрактну» тварину й змусити нащадків реалізувати sound(), використовують абстрактні класи; а інтерфейси описують лише «можливості» без стану. Видимість protected (доступ лише для нащадків) — тут. Усе це — у модулі 7; нам потрібне лише базове наслідування.

6. Практика

Додайте до ієрархії клас Cow (звук «Му»). Створіть open class Vehicle(val brand: String) з open fun wheels(): Int = 4 і похідні Bike (2 колеса) та Truck (6 коліс). Напишіть метод describe() у Vehicle, що друкує марку та кількість коліс.

open class Animal(val name: String) {
    open fun sound(): String = "..."

    fun describe(): String = "$name каже ${sound()}"

    override fun toString(): String = "Animal($name)"
}

class Dog(name: String) : Animal(name) {
    override fun sound(): String = "Гав"

    fun fetch(): String = "$name приносить м’яч"
}

class Cat(name: String) : Animal(name) {
    override fun sound(): String = "Няв"

    override fun toString(): String = "Cat($name) → " + super.toString()
}

// class Puppy : Dog("Бім")           // розкоментуйте: Dog не open, успадковувати заборонено

fun main() {
    val d = Dog("Рекс")
    val c = Cat("Мурка")
    val generic = Animal("Тварина")

    println(d.describe())              // Рекс каже Гав
    println(c.describe())              // Мурка каже Няв
    println(generic.describe())        // Тварина каже ...
    println(d.fetch())                 // Рекс приносить м’яч

    println(d)                         // Animal(Рекс) — toString успадковано
    println(c)                         // Cat(Мурка) → Animal(Мурка)
}
