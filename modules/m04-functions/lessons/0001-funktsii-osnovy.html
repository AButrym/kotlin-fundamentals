Оголошення функції, параметри, тип повернення

Ви вже вмієте писати умови, цикли та працювати з масивами. Функція — спосіб згорнути повторюваний код в один блок з ім'ям, який можна викликати звідусіль.

1. Навіщо функції, якщо є цикли й умови?

Уявіть, що в трьох різних місцях програми потрібно перевірити, чи число просте. Без функцій довелось би копіювати одну й ту саму перевірку тричі. Функція дозволяє написати логіку один раз і викликати її за іменем.

2. Синтаксис оголошення

fun double(x: Int): Int {
    return 2 * x
}

val result = double(21)  // 42

fun — ключове слово. double — ім'я. (x: Int) — параметр з типом. : Int — тип значення, яке функція поверне.

Параметри всередині функції — це val: їх не можна переприсвоїти.

3. Unit — «нічого не повертає»

Якщо функція лише щось виконує (наприклад, друкує на екран) і не повертає значення, її тип повернення — Unit. Це типова поведінка, тож : Unit зазвичай не пишуть:

fun printSum(a: Int, b: Int) {
    println(a + b)
}
Який тип повернення матиме функція, якщо вона нічого явно не повертає (наприклад, лише виконує println)?
Напишіть сигнатуру (без тіла) функції add, яка приймає два Int і повертає Int.
