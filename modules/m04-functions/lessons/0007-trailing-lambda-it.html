Trailing lambda та неявний параметр it

Два синтаксичні скорочення, які роблять виклики з лямбдами коротшими й читабельнішими.

1. Trailing lambda

Коли лямбда — останній аргумент функції, її можна винести за дужки виклику:

fun repeatAction(times: Int, action: (Int) -> Unit) {
    for (i in 1..times) action(i)
}

// звичайний виклик
repeatAction(3, { i -> println("Ітерація $i") })

// trailing lambda — те саме, читається краще
repeatAction(3) { i -> println("Ітерація $i") }

Якщо лямбда — єдиний аргумент, круглі дужки можна прибрати повністю.

2. Неявний параметр it

Якщо лямбда приймає рівно один параметр, його ім'я можна не писати — Kotlin автоматично називає його it:

repeatAction(3) { println("Ітерація $it") }
it працює тільки для лямбд з одним параметром. Для двох і більше параметрів імена потрібно писати явно (як у { x, y -> x + y }).
Перепишіть коротше, з trailing lambda та it: repeatAction(5, { i -> println(i) })
