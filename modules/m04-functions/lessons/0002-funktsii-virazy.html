Функції-вирази (single-expression)

Коротший запис для функцій, тіло яких — один вираз.

1. Коли тіло — один вираз

Якщо все, що робить функція, — це обчислює й повертає один вираз, фігурні дужки, return і навіть тип повернення можна прибрати:

// звичайна форма
fun double(x: Int): Int {
    return 2 * x
}

// функція-вираз
fun double(x: Int) = x * 2

Компілятор сам виводить тип Int з виразу справа від =.

Тип можна опустити тільки для функцій-виразів (з =). Для функцій із тілом у { } тип потрібно писати явно (окрім Unit).

2. Приклад складнішого виразу

fun max(a: Int, b: Int) = if (a > b) a else b

if у Kotlin — теж вираз (повертає значення), тому працює й тут.

Перепишіть у формі функції-виразу: fun square(x: Int): Int { return x * x }
Чи потрібно писати : Int у функції fun triple(x: Int) = x * 3? (так/ні)
