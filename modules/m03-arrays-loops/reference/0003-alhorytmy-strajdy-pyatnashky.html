2. Бульбашка та бінарний пошук

// бульбашка: O(n²), змінює масив на місці
for (pass in 0 until a.size - 1) {
    var swapped = false
    for (i in 0 until a.size - 1 - pass) {
        if (a[i] > a[i + 1]) { val t = a[i]; a[i] = a[i + 1]; a[i + 1] = t; swapped = true }
    }
    if (!swapped) break
}

// бінарний пошук: O(log n), масив відсортований
var lo = 0; var hi = a.size - 1
while (lo <= hi) {
    val mid = lo + (hi - lo) / 2
    when {
        a[mid] == target -> return mid
        a[mid] < target  -> lo = mid + 1
        else             -> hi = mid - 1
    }
}
return -1

3. Страйди

index = row * cols + col
row   = index / cols
col   = index % cols
class Matrix(val rows: Int, val cols: Int) {
    private val data = IntArray(rows * cols)
    private fun checkBounds(row: Int, col: Int) {
        require(row in 0 until rows && col in 0 until cols) { "($row, $col) поза межами" }
    }
    operator fun get(row: Int, col: Int): Int { checkBounds(row, col); return data[row * cols + col] }
    operator fun set(row: Int, col: Int, value: Int) { checkBounds(row, col); data[row * cols + col] = value }
}

4. П’ятнашки 4×4

  • Поле — перестановка 1…16, 16 — порожня клітинка; розв’язане 1, 2, …, 16.
  • Інверсії — пари i < j, a[i] > a[j], без 16.
  • Розв’язуване ⇔ (інверсії + рядок порожньої знизу (1 = нижній)) — непарне.
  • Генерація: Фішер–Йетс → якщо нерозв’язуване, поміняти дві не порожні плитки.
  • Друк: зовнішній цикл по рядках, внутрішній по клітинках, println() після внутрішнього, padStart(3) для вирівнювання.
