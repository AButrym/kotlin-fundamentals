Для уроків 1–3 та 10–11.

1. Створення масиву

ЗаписРезультат / тип

2. Основні операції

ЗаписЗначення
a[i], a[i] = vчитання / запис елемента (індекси з 0)
a.size, a.lastIndex, a.indicesрозмір, останній індекс, діапазон 0 until size
a.contentToString()текстове подання [1, 2, 3]
a.contentEquals(b)порівняння вмісту (== порівнює посилання)
a.copyOf(), a.copyOf(n), a.copyOfRange(from, to)копії; to не входить
a.indexOf(x)індекс першого входження або -1
val b = a — не копія, а аліасинг: обидві змінні вказують на один масив.

4. Типові помилки

  • ArrayIndexOutOfBoundsException — індекс поза 0..lastIndex;
  • очікування, що масив розтягується — розмір фіксований;
  • друк println(arr) замість arr.contentToString();
  • порівняння масивів через == замість contentEquals.
