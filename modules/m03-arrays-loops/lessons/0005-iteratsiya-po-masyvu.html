Ітерація по масиву та матриці

Значення, індекси, withIndex, вкладені цикли.

1. Перебір значень

Якщо потрібні лише значення елементів, for можна застосувати до самого масиву:

val arr = intArrayOf(4, 8, 15, 16)
for (x in arr) {
    print("$x ")      // 4 8 15 16
}
x — це копія значення, до того ж доступна лише для читання. Присвоїти x = x * 2 не можна, а навіть якби було можна, масив би не змінився.

2. Перебір індексів

Щоб змінювати елементи, потрібні індекси. Властивість indices дає діапазон 0 until size:

for (i in arr.indices) {
    arr[i] = arr[i] * 2
}
println(arr.contentToString())   // [8, 16, 30, 32]

Еквівалентні записи: 0 until arr.size, 0..arr.lastIndex.

Для масиву з 6 елементів скільки ітерацій виконає for (i in arr.indices)?

3. Індекс і значення разом: withIndex

for ((i, x) in arr.withIndex()) {
    println("arr[$i] = $x")
}

Запис (i, x) у дужках розкладає пару «індекс — значення» на дві змінні — це деструктуризація. Докладно вона розглядається разом із класами.

Зворотний обхід: for (i in arr.lastIndex downTo 0) або for (i in arr.indices.reversed()).

МетаЯку форму брати
лише прочитати значенняfor (x in arr)
змінити елементи, використати індексfor (i in arr.indices)
потрібні і індекс, і значення для читанняfor ((i, x) in arr.withIndex())
іти назад або з крокомfor (i in arr.lastIndex downTo 0), … step 2

Яка форма цикла дозволяє подвоїти кожен елемент масиву?

4. Вкладені цикли: обхід матриці

Для матриці зовнішній цикл іде по рядках, внутрішній — по клітинках рядка. Довжину рядка беремо з самого рядка — тоді код працює й для зубчастих масивів:

val grid = arrayOf(intArrayOf(1, 2, 3), intArrayOf(4, 5), intArrayOf(6))

for (r in grid.indices) {
    for (c in grid[r].indices) {
        print("${grid[r][c]} ")
    }
    println()                // кінець рядка — після внутрішнього циклу
}
// 1 2 3
// 4 5
// 6

Якщо індекси не потрібні, можна коротше: for (row in grid) for (v in row) print("$v ").

5. Практика

Створіть матрицю Array(3) { IntArray(3) } і заповніть її так, щоб grid[r][c] = r * 3 + c, а потім виведіть рядками. Заповнення діагоналі одиницями (практика з уроку 3) тепер теж можна зробити циклом for (i in grid.indices) grid[i][i] = 1.
