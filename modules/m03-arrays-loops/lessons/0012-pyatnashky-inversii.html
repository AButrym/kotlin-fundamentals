П’ятнашки: інверсії та розв’язуваність

Перестановка 1..16, підрахунок інверсій, виправлення.

1. Постановка

Поле «П’ятнашок» 4×4: числа 1…15 та порожня клітинка. Зручно подати поле перестановкою чисел 1…16, де **16 — порожня клітинка**. Розставлене по порядку 1, 2, …, 15, 16 поле — розв’язане (порожня клітинка внизу праворуч).

Не кожна перестановка розв’язувана: рівно половина з них недосяжна рухами. Якщо просто перетасувати плитки, гра може виявитись нерозв’язною. Нам потрібна перевірка.

2. Інверсії

Інверсія — це пара плиток, що стоять у «неправильному» порядку: перша (зліва) більша за другу (справа), a[i] > a[j] при i < j. Порожню клітинку (16) не враховуємо.

fun countInversions(a: IntArray): Int {
    var count = 0
    for (i in a.indices) {
        if (a[i] == BLANK) continue
        for (j in i + 1 until a.size) {
            if (a[j] != BLANK && a[i] > a[j]) count++
        }
    }
    return count
}

Приклад: у послідовності 3, 1, 2 інверсії — пари (3, 1) і (3, 2), тобто 2. Розв’язане поле має 0 інверсій.

Скільки інверсій у послідовності 2, 1, 3, 4?

3. Правило розв’язуваності для 4×4

Поле розв’язуване тоді й лише тоді, коли (кількість інверсій + номер рядка порожньої клітинки, рахуючи знизу з 1) — непарне число.

Чому це працює. Горизонтальний хід (плитка сусідить із порожньою ліворуч/праворуч) не змінює порядку плиток, тож інверсії й рядок лишаються тими самими. Вертикальний хід переносить плитку через 3 інші, тож кількість інверсій змінюється на непарне число, і водночас змінюється на 1 номер рядка порожньої. Парність суми ніколи не змінюється — а в розв’язаному полі вона непарна. Те, що за непарної суми розв’язок справді існує, — відомий результат теорії П’ятнашок.

const val SIZE = 4        // розмір сторони
const val BLANK = 16      // значення порожньої клітинки

fun isSolvable(a: IntArray): Boolean {
    val blankRow = a.indexOf(BLANK) / SIZE      // 0 = верхній рядок
    val blankRowFromBottom = SIZE - blankRow    // 1 = нижній рядок
    return (countInversions(a) + blankRowFromBottom) % 2 == 1
}

const val — константа з відомим значенням; a.indexOf(BLANK) — це той самий лінійний пошук з уроку 8, але готовий.

Розв’язане поле 1…16: скільки інверсій і який рядок порожньої знизу?

4. Генерація: перемішати й виправити парність

Перемішуємо масив алгоритмом Фішера–Йетса: проходимо з кінця й міняємо a[i] з випадковим елементом a[0..i]. Якщо перестановка нерозв’язувана — міняємо місцями дві будь-які не порожні плитки: це змінює парність інверсій, а рядок порожньої не змінюється.

fun shuffleBoard(a: IntArray) {
    for (i in a.lastIndex downTo 1) {
        val j = Random.nextInt(i + 1)       // 0..i включно
        val t = a[i]; a[i] = a[j]; a[j] = t
    }
}

fun makeSolvableBoard(): IntArray {
    val a = IntArray(SIZE * SIZE) { it + 1 }   // 1..16
    shuffleBoard(a)
    if (!isSolvable(a)) {
        val blank = a.indexOf(BLANK)
        val i = if (blank == 0) 1 else 0       // дві позиції, що не є порожньою
        val j = if (blank <= 1) 2 else 1
        val t = a[i]; a[i] = a[j]; a[j] = t
    }
    return a
}

Не забудьте на початку файла import kotlin.random.Random. Готова функція a.shuffle() теж існує, але алгоритм корисно написати самому.

5. Практика

Складіть вручну поле, де 16 стоїть у верхньому лівому куті, а решта числа йдуть по порядку 1…15. Порахуйте інверсії та рядок порожньої знизу й вирішіть, чи розв’язуване воно. (Підказка: інверсій 0, а порожня — у 4-му рядку знизу.) Перевірте себе isSolvable.
