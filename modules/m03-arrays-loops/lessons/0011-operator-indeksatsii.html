Клас Matrix та оператор індексації

Мінімум про методи класу та operator get/set.

Мініатюрний вступ про методи. Ви бачили класи з полями. Клас може також містити методи — функції, оголошені всередині класу; вони мають доступ до полів. Докладно — у модулі «Класи» (метод, клас); нам потрібне лише це:
class Counter {
    var value = 0
    fun increment() {       // метод
        value++
    }
}

val c = Counter()
c.increment()
println(c.value)            // 1

1. Мета: m[r, c] замість data[r * cols + c]

Сховаємо формулу страйда в класі. Методи зі спеціальними іменами get і set, позначені словом operator, дозволяють компілятору перекладати квадратні дужки в їхні виклики (оператор індексації):

Ви пишетеКомпілятор розуміє як
m[r, c]m.get(r, c)
m[r, c] = vm.set(r, c, v)
m[r, c] += 1m.set(r, c, m.get(r, c) + 1)

2. Клас Matrix

class Matrix(val rows: Int, val cols: Int) {
    private val data = IntArray(rows * cols)

    operator fun get(row: Int, col: Int): Int {
        return data[row * cols + col]
    }

    operator fun set(row: Int, col: Int, value: Int) {
        data[row * cols + col] = value
    }
}

val m = Matrix(3, 4)
m[1, 2] = 7
m[1, 2] += 1
println(m[1, 2])     // 8
  • rows і cols у дужках після імені класу — поля, задані при створенні Matrix(3, 4).
  • private ховає масив data від зовнішнього коду: користуватися матрицею можна лише через m[r, c].
  • Усередині класу формула row * cols + col написана один раз — менше шансів помилитись.
У Matrix(3, 4) який індекс у data має виклик m[2, 3]?

3. Перевірка меж

Пригадайте пастку з уроку 10: (0, 5) у матриці з 4 стовпцями мовчки читає клітинку (1, 1). Додамо перевірку функцією require: якщо умова хибна, вона зупиняє програму з поясненням.

class Matrix(val rows: Int, val cols: Int) {
    private val data = IntArray(rows * cols)

    private fun checkBounds(row: Int, col: Int) {
        require(row in 0 until rows && col in 0 until cols) {
            "($row, $col) поза межами матриці ${rows}x$cols"
        }
    }

    operator fun get(row: Int, col: Int): Int {
        checkBounds(row, col)
        return data[row * cols + col]
    }

    operator fun set(row: Int, col: Int, value: Int) {
        checkBounds(row, col)
        data[row * cols + col] = value
    }
}

Повідомлення в фігурних дужках після require — лямбда (її виконують, лише якщо перевірка не пройшла).

Яка перевага m[r, c] над data[r * cols + c]?

4. Практика

Додайте до Matrix метод fun fill(value: Int), який заповнює всю матрицю одним значенням (цикл по data.indices). Потім заповніть матрицю 3×4 значеннями r * 10 + c вкладеними циклами через m[r, c] = ….
