Цикли while та do-while

Коли кількість повторів невідома наперед.

1. while: «поки умова істинна»

Цикл for зручний, коли кількість повторів відома. Якщо ж ми не знаємо, скільки кроків знадобиться, використовуємо [[while-loop|while]]: умова перевіряється перед кожним проходом.

var n = 1234
var sum = 0
while (n > 0) {
    sum += n % 10     // остання цифра
    n /= 10           // відкидаємо її
}
println(sum)          // 10
Тіло циклу має змінювати те, від чого залежить умова. Інакше цикл нескінченний — програма «зависне».
Скільки разів виконається тіло var i = 0; while (i < 3) { i++ }?

2. Приклад: найбільший спільний дільник

Алгоритм Евкліда: поки b не нуль, замінюємо пару (a, b) на (b, a % b).

var a = 48
var b = 18
while (b != 0) {
    val t = a % b
    a = b
    b = t
}
println(a)    // 6

3. do-while: спершу виконати, потім перевірити

У do { … } while (умова) умова стоїть після тіла, тому тіло виконується щонайменше один раз:

var x = 10
do {
    println("do-while: x = $x")   // надрукується один раз
    x++
} while (x < 5)

while (x < 5) {
    println("while")              // не виконається жодного разу
}

Типове застосування — запит введення, який треба показати хоча б раз і повторювати, поки користувач не введе коректне значення:

var age: Int
do {
    print("Вік (1..120): ")
    age = readln().toInt()
} while (age !in 1..120)

Скільки разів виконається тіло var k = 10; do { k++ } while (k < 5)?

4. for чи while?

СитуаціяЦикл
кількість повторів відома (діапазон, масив)for
повторювати, доки не виконається умова (кількість невідома)while
тіло має виконатись хоча б разdo-while

5. Практика

Гіпотеза Коллатца: якщо число парне — поділіть на 2, інакше — помножте на 3 і додайте 1. Рахуйте кроки до досягнення 1, починаючи з n = 6 (очікується 8 кроків). Спробуйте інші стартові числа.
