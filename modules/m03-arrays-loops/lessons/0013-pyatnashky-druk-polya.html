П’ятнашки: друк поля

Обхід по рядках і клітинках: масив масивів проти страйдів.

1. Що друкуємо

Поле 4×4 хочемо побачити як сітку: числа вирівняні в стовпчики, порожня клітинка — пробіли. Загальна схема будь-якого друку таблиці — обхід по рядках і клітинках:

for (кожен рядок) {
    for (кожна клітинка рядка) {
        надрукувати клітинку (без переходу на новий рядок)
    }
    перейти на новий рядок      // println() — вже ПІСЛЯ внутрішнього циклу
}

Де має стояти println() для переходу на новий рядок?

2. Вирівнювання клітинок

text.padStart(3) доповнює рядок пробілами зліва до довжини 3: "7".padStart(3) → " 7". Порожню клітинку показуємо порожнім рядком — вона теж займе 3 пробіли.

Скільки пробілів додасть "7".padStart(3)?

3. Варіант А: масив масивів

fun printBoardRows(board: Array<IntArray>) {
    for (r in board.indices) {
        for (c in board[r].indices) {
            val v = board[r][c]
            val text = if (v == BLANK) "" else v.toString()
            print(text.padStart(3))
        }
        println()
    }
}

4. Варіант Б: страйди та m[r, c]

Клас Matrix з уроку 11 ховає формулу r * cols + c; обхід виглядає майже так само, але без вкладених масивів:

fun printBoardMatrix(m: Matrix) {
    for (r in 0 until m.rows) {
        for (c in 0 until m.cols) {
            val v = m[r, c]
            val text = if (v == BLANK) "" else v.toString()
            print(text.padStart(3))
        }
        println()
    }
}

Для П’ятнашок обидва варіанти рівноправні. Масив масивів простіший для старту, Matrix — зручніша основа, коли в поля з’являтимуться перевірки, копії та інші дії: на цьому ж полі ви будуватимете наступні програми курсу.
