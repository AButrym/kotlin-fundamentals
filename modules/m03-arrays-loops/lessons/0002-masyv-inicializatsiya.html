Ініціалізація, копіювання та порівняння масивів

IntArray проти Array<Int>, друк, посилальна семантика.

1. Способи створити масив

val a = arrayOf("a", "b", "c")          // Array<String>
val b = intArrayOf(1, 2, 3)             // IntArray
val zeros = IntArray(5)                 // [0, 0, 0, 0, 0]
val squares = IntArray(5) { it * it }   // [0, 1, 4, 9, 16]
val names = Array(3) { i -> "Student$i" }  // [Student0, Student1, Student2]

У фігурних дужках — лямбда: вона викликається для кожного індексу 0 … size − 1, а її результат стає значенням елемента. Деталі лямбд — у модулі «Функції»; поки що читайте { it * it } як «елемент = індекс у квадраті».

2. Array<Int> чи IntArray

Array<Int>IntArray

Для чисел, символів і булевих значень зручніше й ефективніше брати спеціалізовані масиви: IntArray, LongArray, DoubleArray, CharArray, BooleanArray — це масиви примітивів. Для рядків та інших типів — Array<T>.

3. Друк і порівняння

val a = intArrayOf(1, 2, 3)
println(a)                      // [I@1b6d3586 — адреса, а не вміст
println(a.contentToString())    // [1, 2, 3]

val b = intArrayOf(1, 2, 3)
println(a == b)                 // false — різні об’єкти
println(a.contentEquals(b))     // true  — однаковий вміст
Скільки елементів-нулів має IntArray(7)?

4. Копіювання й аліасинг

Масив — посилальний тип. Присвоєння val b = a не копіює масив: обидві змінні вказують на той самий об’єкт (аліасинг).

val a = intArrayOf(1, 2, 3)
val alias = a               // ті самі дані
val copy = a.copyOf()       // незалежна копія

alias[0] = 99
println(a.contentToString())     // [99, 2, 3]
println(copy.contentToString())  // [1, 2, 3]

a.copyOf(5)           // [99, 2, 3, 0, 0] — збільшена копія
a.copyOfRange(1, 3)   // [2, 3]          — від 1 включно до 3 не включно
Після val b = a; b[0] = 99 яке значення має a[0], якщо раніше воно було 1?

Яка змінна змінюється, якщо виконати copy[0] = 5, де val copy = a.copyOf()?

5. Практика

Створіть IntArray із шести перших парних чисел 0, 2, 4, 6, 8, 10, використавши лямбда-ініціалізатор. Зробіть копію, змініть її й переконайтеся, що оригінал не змінився.
