Лінійний пошук, підрахунок, сума, мінімум

Базові шаблони обходу масиву.

**Невеличка примітка про fun.** Далі алгоритми зручно оформлювати функціями. Поки що читайте шаблон так: fun назва(параметр: Тип): ТипРезультату { … return значення }. Функцію викликають за ім’ям: назва(аргумент). Усе про функції — у наступному модулі, а тут ми їх лише використовуємо.

1. Лінійний пошук

Лінійний пошук: переглядаємо елементи по черзі; знайшли — повертаємо індекс, не знайшли — -1 (бо -1 ніколи не є коректним індексом).

fun linearSearch(arr: IntArray, target: Int): Int {
    for (i in arr.indices) {
        if (arr[i] == target) return i
    }
    return -1
}

У гіршому випадку переглядаємо всі n елементів — кажуть, що складність O(n) (час зростає пропорційно розміру масиву).

Що поверне linearSearch(intArrayOf(5, 7, 9), 9)?

2. Підрахунок за умовою та сума

fun countPositive(arr: IntArray): Int {
    var count = 0
    for (x in arr) {
        if (x > 0) count++
    }
    return count
}

fun sum(arr: IntArray): Int {
    var total = 0
    for (x in arr) total += x
    return total
}

Шаблон: акумулятор (count, total) ініціалізуємо нейтральним значенням (0) і оновлюємо в циклі.

3. Мінімум і максимум

fun maxValue(arr: IntArray): Int {
    var best = arr[0]               // не 0!
    for (i in 1 until arr.size) {
        if (arr[i] > best) best = arr[i]
    }
    return best
}
Починати з best = 0 — помилка для масивів лише з від’ємними числами. Початкове значення — перший елемент. Для порожнього масиву такий код впаде: це треба перевіряти окремо.

Що поверне наївний max, який стартує з best = 0, для [-5, -2, -9]?

4. Узагальнення: умова як параметр

Підрахунок «додатних», «парних», «більших за 10» відрізняється лише умовою. Умову можна передати як лямбду — ось підгляд у наступний модуль:

fun countIf(arr: IntArray, predicate: (Int) -> Boolean): Int {
    var count = 0
    for (x in arr) {
        if (predicate(x)) count++
    }
    return count
}

countIf(intArrayOf(3, -1, 8, 0)) { it > 0 }       // 2
countIf(intArrayOf(3, -1, 8, 0)) { it % 2 == 0 } // 2 (8 і 0)
Готові arr.sum(), arr.count { … }, arr.max() існують у стандартній бібліотеці (їх розбирають у модулі «Колекції»). Ми пишемо їх самі, щоб відчути, як працює цикл під капотом.

5. Практика

Напишіть minIndex(arr: IntArray): Int — індекс найменшого елемента; і average(arr: IntArray): Double (сума, поділена на розмір; подумайте, що зробити з цілочисельним діленням).
