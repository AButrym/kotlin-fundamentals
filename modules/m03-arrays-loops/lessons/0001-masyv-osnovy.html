Масив: створення та індексація

Як зберегти багато значень одного типу під одним іменем.

1. Навіщо потрібен масив

Досі кожне значення жило у власній змінній. Щоб зберегти оцінки 30 студентів, не можна ж оголошувати score1, score2, …, score30. Масив (array) — це впорядкована послідовність елементів одного типу, що має одне ім’я й фіксований розмір. Окремий елемент вибирають за номером — індексом.

val scores = arrayOf(5, 3, 8, 1)

println(scores[0])      // 5  — перший елемент
println(scores.size)    // 4  — кількість елементів
Індекси починаються з нуля. Перший елемент — scores[0], останній — scores[scores.size - 1] (або коротше scores[scores.lastIndex]).
Масив має 5 елементів. Який індекс має останній із них?

2. Читання й запис елементів

Квадратні дужки працюють в обидва боки: і для читання, і для запису.

val scores = arrayOf(5, 3, 8, 1)
scores[1] = 10                // тепер [5, 10, 8, 1]
scores[2] = scores[2] + 1     // тепер [5, 10, 9, 1]
val scores означає, що змінна scores завжди вказує на той самий масив. Але вміст цього масиву змінювати можна — про це докладніше в наступному уроці.

3. Розмір фіксований, а межі перевіряються

Розмір масиву не змінюється після створення: додати шостий елемент у масив із п’яти не можна. (Структури, що ростуть, — колекції — буде в окремому модулі.) Спроба звернутися до неіснуючого індексу не «тихо» читає чужу пам’ять, а зупиняє програму винятком:

val scores = arrayOf(5, 3, 8, 1)
println(scores[4])
// Exception ... ArrayIndexOutOfBoundsException: Index 4 out of bounds for length 4

Що станеться при виконанні scores[scores.size] для непорожнього масиву?

4. Практика

Створіть масив із п’яти температур. Замініть третє значення на 20, потім виведіть перше значення, останнє значення та розмір масиву.
