Матриця в одновимірному масиві: страйди

index = row * cols + col.

1. Проблема масиву масивів

Array<IntArray> — це масив посилань на окремі масиви. Кожен рядок — окремий об’єкт у пам’яті, а будь-яка операція над усією таблицею (копіювання, заповнення, передача) змушує окремо обходити рядки. Альтернатива — зберегти всю таблицю в одному IntArray розміру rows * cols, рядок за рядком.

// матриця 3 × 4 розкладена в один масив:
//  рядок 0: індекси 0..3
//  рядок 1: індекси 4..7
//  рядок 2: індекси 8..11
val data = IntArray(3 * 4)

2. Формула страйда

Страйд (крок) — кількість елементів між початками сусідніх рядків; для «рядок за рядком» він дорівнює кількості стовпців cols.

index = row * cols + col

row = index / cols      // цілочисельне ділення
col = index % cols      // остача
(row, col)Обчислення при cols = 4index
(0, 0)0 · 4 + 00
(1, 2)1 · 4 + 26
(2, 1)2 · 4 + 19
(2, 3)2 · 4 + 311
Матриця має cols = 5. Який row у елемента з індексом 13? (13 / 5 цілочисельно)
У матриці cols = 4 який індекс у масиві має клітинка (2, 3)?

3. Обхід і заповнення

val rows = 3
val cols = 4
val data = IntArray(rows * cols)

for (r in 0 until rows) {
    for (c in 0 until cols) {
        data[r * cols + c] = r * 10 + c
    }
}
println(data.contentToString())   // [0, 1, 2, 3, 10, 11, 12, 13, 20, 21, 22, 23]

Хочете ітерувати рівно один раз по всіх клітинках без пар (r, c) — достатньо for (i in data.indices), а r/c обчислити за формулою обернено.

4. Порівняння двох подань

Array<IntArray>один IntArray + страйд
Зверненняgrid[r][c]data[r * cols + c]
Об’єктів у пам’яті1 + rows1
Копіюванняпотрібно копіювати кожен рядокодин copyOf()
Рядки різної довжинитак (зубчасті)ні — завжди прямокутник
Ризик помилки у формулінемаєє (виправимо в наступному уроці)
Без перевірки меж data[r * cols + c] легко прочитати чужу клітинку: для cols = 4 пара (0, 5) дасть індекс 5 — це клітинка (1, 1), і жодної помилки не буде.
У наступному уроці сховаємо формулу всередині класу, а доступ зробимо таким же зручним, як grid[r][c] — тобто m[r, c].

5. Практика

Заповніть одновимірний масив для матриці 3×4 числами r * 10 + c і виведіть його рядками, використовуючи формулу. Окремо для індексу 7 обчисліть row та col двома рядками val.
