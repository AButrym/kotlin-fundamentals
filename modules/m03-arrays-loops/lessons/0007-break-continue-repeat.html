break, continue, мітки та repeat

Керування ходом циклу та найпростіше повторення.

1. break і continue

  • break — негайно завершує найближчий цикл;
  • continue — пропускає решту тіла й переходить до наступної ітерації.
for (i in 1..10) {
    if (i % 2 == 0) continue    // парні пропускаємо
    if (i > 7) break            // зупиняємось після 7
    print("$i ")                // 1 3 5 7
}

Часта схема — «нескінченний» цикл із виходом всередині:

var attempts = 0
while (true) {
    attempts++
    if (attempts == 3) break
}
println(attempts)   // 3
Що надрукує for (i in 1..5) { if (i == 3) break; print(i) }? Введіть лише цифри без пробілів.

2. Мітки: вихід з вкладених циклів

break у внутрішньому циклі виходить лише з нього. Щоб завершити зовнішній, ставимо на цикл мітку ім’я@ і пишемо break@ім’я:

outer@ for (i in 1..9) {
    for (j in 1..9) {
        if (i * j == 12) {
            println("Знайдено: $i * $j = 12")
            break@outer          // виходимо з обох циклів
        }
    }
}

Аналогічно continue@outer переходить до наступної ітерації зовнішнього циклу.

Скільки разів виконається print у for (i in 1..3) { for (j in 1..3) { if (j == 2) continue; print("x") } }?

3. repeat(n)

Коли потрібно просто виконати блок n разів і лічильник не потрібен, зручна функція repeat:

repeat(3) {
    println("Привіт!")
}

repeat(3) { index ->
    println("Повтор №$index")    // 0, 1, 2
}

Блок у фігурних дужках — це лямбда, що передається функції вищого порядку repeat; докладно — у модулі «Функції». Через це break та continue у repeat не використовують: потрібен вихід — беріть for або while.
