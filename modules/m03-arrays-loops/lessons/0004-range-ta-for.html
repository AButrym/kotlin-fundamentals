Діапазони та цикл for

..<, until, downTo, step.

1. Діапазон і цикл for

Діапазон — це послідовність значень від початку до кінця. Цикл for перебирає її по одному значенню:

for (i in 1..5) {
    print("$i ")      // 1 2 3 4 5
}

Змінна i оголошується самим циклом, і в кожній ітерації вона дорівнює наступному значенню діапазону.

ЗаписЗначенняПримітка
1..51 2 3 4 5кінець включно
1 until 51 2 3 4кінець не входить
1..<51 2 3 4те саме, що until, оператор (Kotlin 1.9+)
5 downTo 15 4 3 2 1у зворотному напрямку
1..10 step 31 4 7 10крок; має бути додатним
10 downTo 0 step 510 5 0спадання з кроком
(1..5).reversed()5 4 3 2 1переворот наявного діапазону
Скільки ітерацій виконає for (i in 1 until 5)?
Типовий вибір для проходу по індексах масиву розміру n — 0 until n (або 0..<n): останній індекс n не входить.

2. Порожній діапазон

5..1 — порожній діапазон: .. завжди рахує вгору. Цикл просто не виконається, помилки не буде. Для спадання пишіть 5 downTo 1.
Скільки ітерацій виконає for (i in 5..1)?

3. Перевірка належності

Діапазон — не лише для циклів. Оператори in та !in перевіряють, чи потрапляє значення в діапазон. Працює й для символів:

val x = 7
println(x in 1..10)         // true
println(x !in 1..10)        // false
println('x' in 'a'..'z')    // true

for (ch in 'a'..'e') print(ch)   // abcde

Яка послідовність 10 downTo 1 step 3?

4. Практика

Виведіть у рядок числа 10, 8, 6, 4, 2, 0 одним циклом for. Потім — літери від 'z' до 'u' у зворотному порядку.
